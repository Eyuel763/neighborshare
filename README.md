# NeighborShare

NeighborShare is a Flutter + Firebase mobile app for local sharing. It helps neighbors list tools or services (skills), discover nearby listings, and coordinate requests and chats within their city/sub-city area.

## Features

- **Authentication** with Firebase Auth (email/password and Google sign-in).
- **Profile setup** for city and sub-city to localize listings.
- **Listings** for tools and skills with categories, pricing, and images.
- **Nearby discovery** with search and type filters (Tool / Skill).
- **Requests & activity** to track borrowing/service requests.
- **In-app chat** between requester and owner.

## Tech Stack

- Flutter (Material 3)
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Google Sign-In

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- A Firebase project
- Android Studio / Xcode (for mobile builds)

### Firebase Setup

This project expects Firebase configuration files to be present locally (they are gitignored).

1. **Create a Firebase project** in the Firebase console.
2. **Configure FlutterFire** and generate `firebase_options.dart`:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
3. Add platform config files as needed:
   - `android/app/google-services.json`
   - `ios/Runner/GoogleService-Info.plist`

### Install Dependencies

```bash
flutter pub get
```

### Run the App

```bash
flutter run
```

## Project Structure

```
lib/

  models/      # Data models (user, listing, request, message, review)
  screens/     # UI screens (home, listing details, chat, profile, etc.)

  widgets/     # Reusable UI widgets
```

## Testing

```bash
flutter test
```

## Notes

- `lib/firebase_options.dart` is generated by FlutterFire and is not committed.
- If you update Firebase settings, re-run `flutterfire configure`.
